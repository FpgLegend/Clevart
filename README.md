# Clevart – Smart Shopping Cart Navigation System

## Project Overview
Clevart is a smart shopping cart system designed to improve the supermarket shopping experience.

The system aims to help customers locate products, navigate supermarket aisles, manage shopping lists, and track their spending while shopping.

Clevart combines a cart-mounted display, indoor localization, product information, and route-planning algorithms to provide an interactive shopping experience.

## Problem Statement
Customers may experience several difficulties while shopping in supermarkets, such as:

- Spending time searching for products.
- Not knowing the exact location of items.
- Walking through unnecessary aisles.
- Forgetting items from their shopping lists.
- Having difficulty keeping track of their spending.

Clevart aims to address these challenges through an integrated navigation and shopping assistance system.

## Proposed Features
The planned system includes:

1. **Indoor Navigation:** Estimate the shopping cart's location inside the supermarket.
2. **Product Search:** Help customers find products and their locations.
3. **Route Planning:** Calculate efficient routes based on shopping lists.
4. **Dynamic Rerouting:** Update routes when customers change their shopping plans.
5. **Shopping Lists:** Allow customers to create and manage lists.
6. **Budget Tracking:** Estimate the running total and help customers monitor their budget.
7. **Product Database:** Store product details, prices, and locations.
8. **Cart-Mounted Display:** Provide the main interface for navigation and shopping assistance.
9. **Mobile Integration:** Support shopping lists, purchase history, and user settings.

## System Components
The proposed system involves:

- Cart-mounted display
- Indoor localization technology
- Product database
- Route-planning algorithms
- Backend software
- Wireless communication
- Mobile application integration

The final technologies and components will be selected during the design and testing stages.

## Project Objectives
- Improve the supermarket shopping experience.
- Reduce unnecessary time spent searching for products.
- Provide useful product-location information.
- Support organized shopping.
- Develop and evaluate a working smart cart prototype.
